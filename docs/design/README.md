## 结论的使用方式

| 类别 | 当前记录 |
| --- | --- |
| 架构方向 | 主协调与职责型专业 Agent；按需调用而非固定遍历全部节点 |
| 工具方向 | 统一工具管理与执行边界；业务职责和接入方式分别分类 |
| MCP 方向 | Java 模拟服务验证通用接入，后续可接其他服务；保留协议结果与领域候选 |
| 意图方向 | 上下文规则、一次模型结构化判断、后端校验；不先堆叠独立识别 Agent |
| RAG 推荐基线 | PostgreSQL + pgvector，结构切分，关键词与向量召回、融合和重排 |
| 待评估参数 | 分块长度、重叠、召回数量、模型型号、索引与分类阈值；不是已经验证的最优值 |
| 已实现与验收 | 单独查看 [进度](../progress.md)、源码和任务报告，不能由设计标题推断 |
