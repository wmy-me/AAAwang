## 目标

把现有对话意图识别整理为独立、清晰且实际使用的一层，供主 Agent 决策。用户保持自然语言聊天：普通问题直接文本回答；涉及商品或方案时按实际数据展示现有卡片。复用已有执行链，不建立第二套路由或 Worker。

用户已决定 031 先保留 Mem0 接入代码、真实 Embedding 和数据库联调暂缓。当前只有 DeepSeek 模型 API；没有其他已配置模型或 Embedding 服务。禁止把 BGE-M3 下载、uv sync、031 数据库迁移或真实 Mem0 验收作为本任务前置条件。记忆默认关闭、原有对话继续可用；不声称记忆已真实可用。

## 开始前

读取根目录 AGENTS.md、CLAUDE.md（存在时）、030/031 报告及相关代码。梳理 `coordinator/service.py` 的 `classify_conversation_turn`、`decide_capabilities`，`modules/chat/service.py`、`modules/capabilities/routing.py` 与 `worker/runner.py` 的生产调用、回退及现有测试。说明将替换或保留的路径，避免新增并行分类器。参考 GoGo 只借鉴职责边界，不照搬类或流程。不要自动启动备用 Compose。

## 实施范围

1. 在现有后端包中建立单一意图识别入口（例如 `intent/`），将现有模型分类提示词、结构化结果与校验放在职责清晰的位置；实际 Worker 对话请求必须走此入口，迁移重复实现或保留明确的兼容转发，不能仅新增空包。明确输入为本轮消息、受认证用户约束的有限会话/任务上下文；结果为受校验的判断、任务引用、必要澄清线索等。
2. 识别普通对话、新需求、继续/修改既有任务、明确的记忆操作与歧义；不按商品类别硬编码业务流程。理解指代，任务不唯一时自然语言澄清。复合请求不能静默丢失子意图：若现有架构尚不能安全处理，明确追问或说明而非假称全部完成；不要求此阶段实现完整多步骤复合执行器。
3. 保持模型辅助判断，输出不等于授权；工具/能力选择仍由主协调在注册能力范围内按需决定，白名单、用户归属、参数校验、共享预算和停止条件由服务端强制执行。不要硬编码“每个购物需求必须经过地图→商品→规划”。普通聊天不触发不必要工具或硬性表单。教师奖品仅为示例，不新增专用场景、Skill 或硬编码关键词。
4. 收敛 Worker 中与意图判断重复的业务决策：仅在能保持既有行为的范围抽取，Worker 继续负责租约、取消、fencing、持久化和预算。保持现有商品、地图、天气、网页能力和聊天文本/卡片契约；不要为目录整齐打散 Agent 或建立空子目录。
5. 保留 031 记忆路由和禁用时降级。修正已发现的 `forget` 要求 `memory_value` 非空的问题：删除无需新值；确保有服务端用户隔离，匹配不唯一时先澄清。可以用替身做一项针对性检查，不运行真实模型验收或安装新的模型；031 真实联调仍记录待补。
6. 分类失败、超时或结构不合法时沿用或明确安全回退，不能误触发记忆写入、删除或越权工具；不记录完整敏感信息。现有共享调用预算、历史上下文、会话归属和任务 revision 不得绕过。

## 精简验证与收口

- 运行必要的少量针对性验证：普通聊天不调用外部业务工具；自然语言新任务及“换一个”等追问正确进入现有链路；含记忆和查询的复合意图不静默丢失；删除无需新值、跨用户不可操作。已有替身可复用，按改动运行项目已有检查，不要求全量测试或浏览器矩阵。
- 如果本地 DeepSeek 可用，可通过现有对话入口做一次短的真实对话冒烟；不可用时不阻塞代码收口，报告如实说明。不得声称未执行的真实模型、真实 Mem0 或数据库验证通过。
- 更新任务报告、进度和索引，写明代码入口、少量验证及未验证项。031 记忆真实联调仍是待补项；不要求用户当前提供任何额外模型或 Key。完成后停止，不自动实施 033。
