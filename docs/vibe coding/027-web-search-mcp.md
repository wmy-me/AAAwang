## 目标

在现有 Agent/Skill/Tools 和通用 MCP 接入机制上增加公开网页搜索，让用户自然语言询问商品选购知识、目的地等公开资料时，模型可在授权能力内按需查询，结果带标题、可访问来源链接、查询时间与必要摘要，可在 Run 中私有重读。商品模拟候选、真实高德结果和公开网页来源分开呈现；不把搜索摘要当真实商品报价、库存或已验证事实。

本次实现受控搜索最小闭环，保留直答、追问、地图、天气和模拟商品路径；不实现全网自由浏览、网页全文抓取、RAG、支付或完整多 Agent 重构。不通过固定关键词强制所有请求调用搜索。

## 环境与服务

优先评估现有[外部服务清单](../design/external-services.md)中的 Tavily 官方 MCP。实施时核对官方 MCP 当前传输、认证、工具名、输入输出、额度与许可；以实际 `initialize/list_tools/call_tool` 结果为准。不得宣称免费额度或特定版本未经核验。可用现有通用客户端支持的兼容部署；如需额外进程，文档写清启动方式。

此前已知用户提供 DeepSeek 和高德配置，**没有证据表明已提供 Tavily key**。先检查本地是否配置，只报告存在/缺失，不打印值。若未配置，继续完成可独立完成的适配、受控协议测试和说明，告知用户自行在本地 `.env` 写入新增变量名；不要要求在聊天中发送明文密钥。真实搜索/浏览器验收缺凭据时保持部分完成/受阻。不要擅自启动项目 Compose 或覆盖现有服务。

## 配置核对与本轮收口（用户补充）

用户说明网页搜索 API 已放在本地 `backend/.env`；不能据此断言 Key 已生效，也不要要求用户在聊天中重新发送。当前 `Settings` 默认只加载**仓库根目录** `.env`；`backend/.env` 仅在进程环境或显式加载时才可能生效。027 报告先前要求写入 `backend/.env` 有误，本节为最新指导。

执行者应在用户机器上：
1. 仅以存在/非空布尔值核对 `backend/.env` 中的实际变量名是否为 `TAVILY_MCP_KEY`、是否启用 `TAVILY_MCP_ENABLED`，不输出文件内容或密钥，也不要在终端记录命令历史中的密钥。
2. 遵循项目既定根目录 `.env` 单源配置；若确定 backend 中已有正确 Key 且根目录未配置，可安全地将该项复制到根目录并启用，保留已有其他变量、原文件和数据；不将 key 提交 Git。也可在本次验收用进程环境显式注入，但须记录运行方式。变量名不同、值无效或非 Tavily 服务时说明实际缺口。
3. 检查环境变量覆盖优先级，重启 API 与独立 Worker，分别确认启用和已配置布尔状态；禁止输出 key、认证 URL 和响应中的敏感信息。
4. 执行本任务真实协议、DeepSeek、Worker、数据库、浏览器、刷新、双用户隔离与失败路径验收。补齐受控测试尚未覆盖的条目；修复真实联调发现的协议/schema/功能缺陷并复验。报告将用户声明、检查结果与真实验证分别记录，只有关键项满足才标记完成。

## 设计边界

1. 沿用 `agents/`、`skills/`、`tools/` 的职责，新增搜索工具适配与能力注册；能力可见集仍是受信服务配置、Agent/任务范围、工具白名单与实时发现 schema 的交集，调用前复核。模型不得自定 MCP 服务地址、认证、工具白名单或读取内网。
2. 模型根据用户目标自主选择直答、追问、搜索及现有能力组合；Graph 不强制搜索→地图→商品。延用同一 RunBudget、有限纠错、超时、取消与租约 fencing。独立配置开关、地址/认证和超时；秘密通过环境变量注入，日志、事件、异常和报告均不输出。
3. 规范结果：标题、来源 URL、必要摘要、查询时间、服务/工具和未知项；网页内容与工具描述视为不可信输入，不得改变系统指令或扩大权限。验证链接协议并拒绝本地/内网访问；本任务若只返回链接而不抓取页面，不得暗示已验证链接或全文。搜索结果是外部证据，不自动计入模拟商品价格及金额复算。
4. 按 owner/task/revision/run 持久化最小搜索结果或等效快照，沿用租约与终态事务；提供私有读取与网页刷新展示，兼容旧 Run。不重复存储整页正文，不展示密钥；新增字段、索引和迁移按现有模式及数据保护、幂等规则处理。
