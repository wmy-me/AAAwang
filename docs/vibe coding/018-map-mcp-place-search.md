## 1. 目标和边界

P3 已验证模拟商品候选、方案调整与任务条件一致性。P4 的第一个小任务通过现有 Python 通用 MCP 客户端接入一项真实地图服务的只读地点查询，首选设计清单中的高德官方 MCP。用户能在明确地点范围内查询附近可供采买的店铺/地点，看到可追溯来源与查询时间。保留现有 shopping-mcp 模拟商品和服务端金额计算，地图 POI 只表示地点资料，不自动给出商品报价、库存、营业实时保证或购买方案的可信价格。

本轮仅地点/POI 搜索和必要的地点解析；路线、天气、Tavily、真实商品价格、自动下单、P5 文档 RAG、P6 出行规划另拆任务。不建设另一个 Java 业务后台。第三方免费政策与配额在实施时从官方文档和用户账号后台核对，不在代码中固化额度数字。

## 2. 开始前核对

阅读 `AGENTS.md`、`CLAUDE.md`、[进度](../progress.md)、[路线图](../roadmap.md)、[Agent 执行预算](../design/agent-execution-rules.md)、[数据保护与幂等](../design/security-and-idempotency.md)、现有 MCP 注册和工具循环、`shopping_agent` 的发现职责与任务上下文。实施时以官方服务实际传输、认证、工具 schema、参数及条款为准；不要把健康检查或本地替身视作真实远端 MCP 调用。检查服务是否支持项目当前的 Streamable HTTP 客户端，不能用未经验证的 URL 或固定工具名假装兼容。

## 3. 实施要求

1. **凭据和配置**：将外部地图服务设为可选配置，未配置时项目、原有购物闭环照常启动，使用该功能时返回可理解的“未配置”。凭据只从本地环境或部署秘密注入，不提交 Git、日志、Run、响应或模型上下文。核对远端鉴权方式，避免含 Key 的完整 URL 被代理、异常或审计记录；若现有 MCP 客户端不支持所需鉴权，扩展通用客户端的受限配置和请求处理。
2. **工具注册与权限**：为远端服务分配稳定 service ID，经实际握手、list tools 和 schema 校验后只向信息发现 Agent 暴露批准的只读地点工具。服务 ID、允许工具、超时及输入边界由后端配置控制；模型不能传任意 URL、凭据、其他用户身份或自由注册新 MCP 服务。沿用共享模型/工具预算，远端调用、失败尝试和取消均计数。
3. **输入和结果**：地点查询要求明确城市或位置范围；地点不明确时追问，不猜用户位置或擅自发送设备定位。对输出做字段白名单与长度限制，保存服务名、工具名、地点名、地址/坐标（如有）、查询时间、原始来源标识和可验证链接（如有）。无法验证的字段标注未知；坐标系在跨服务使用前明确。外部 MCP 文本按不可信资料处理，不执行其中指令。
4. **已有购物流程**：选定购物任务可请求“在指定城市找附近的礼品店”并获得独立的地点证据，不将 POI 混进 `shopping_candidates` 的可计价商品。现有奖品采买方案仍按模拟候选计算与显示来源；地图服务失败或限流不产生假店铺，也不伪称商品涨跌价。若当前图需要新增发现分支，更新决策描述和工具允许列表，保持主从调用次数硬上限；不得默默放宽上限。
5. **持久化与隔离**：需要刷新后查看的地点结果按当前用户、任务、revision、Run 存储受控字段；若首版仅在当前回答展示，应在契约和报告说明刷新行为。任何对话/Run 读取继续按 owner 过滤，重复请求和旧 Worker 迟到结果遵循现有幂等与 fencing。避免缓存跨用户私有任务上下文。
6. **错误语义**：区分未配置、认证失败、协议不兼容、额度/限流、超时和合法空结果；不自动无限重试。远端只读请求可能消耗配额，记录次数而不记录凭据。无真实凭据时可完成本地接口和替身验证，但任务保留“待真实验收”，不能标为完成。

## 4. 验收

| 场景 | 通过标准 |
| --- | --- |
| 真实远端 MCP | 在用户提供的合法凭据和允许条件下，真实初始化、工具发现、schema 校验与一次地点查询通过；记录协议和实际工具名、调用次数，不公开凭据 |
| 购物场景 | 指定地点的店铺资料有来源与时间，网页可按定义读取；商品仍标记模拟，预算复算不受地点结果替代 |
| 边界 | 缺位置先追问；无 Key、错误 Key、限流/超时、空结果均有区分；越权、工具白名单及超限请求被阻止 |
| 回归 | 001–017 的相关购物与账号隔离路径仍可用；Python 测试/Ruff、必要迁移与 `alembic check`、前端 lint/build 通过；按实际改动验证 Java 构建 |
| 报告 | 明确真实远端、真实 DeepSeek/数据库/浏览器、Java 模拟 MCP 与替身分别验收了什么；未获凭据或不符合条款时注明受阻原因 |

完成后更新接口/工具契约、开发说明、任务索引、进度和路线图，提交报告后停止。外部服务凭据及控制台免费额度需要用户在开始真实联调前提供或自行配置，不写入报告。
